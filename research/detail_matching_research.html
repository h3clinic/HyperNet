Preserve fine evidence, then test it on new compositions

Research and design review, not a new benchmark result. The original goal remains recognizing any natural example of the same type from one reference. The current controlled 2D probe tests fine-pattern identity inside clutter. No source below proves our proposed method will achieve that broader goal.

The previous run generated a suitable target proposal in every positive TEST scene, but final matching stayed weak. A whole-patch similarity can be dominated by unchanged outline and background pixels. A second issue is score comparability: ordering a positive above its paired negative does not guarantee a common threshold will separate positives and negatives across different compositions.

Proposed controlled comparison

Reuse the exact existing proposal CNN trained only on our synthetic TRAIN data. Estimate broad alignment from image-derived geometry, then keep native detail separately. Both the full method and its detail ablation should receive identical proposals, alignment candidates, input images and enrollment sources. Otherwise an apparent detail gain could actually come from easier cropping, more alignment search or a changed proposal roster.

Here C and F denote proposed coarse and fine image-derived evidence, not a finalized architecture. Estimate g without fine labels. Normalize the fine channel by its own visible information, with explicit low-energy abstention, rather than by the total silhouette area. Retain local coordinates: averaging all orientations can erase the very distinction being tested. If interior holes are explicitly extracted, that is a domain-specific analytic prior. A hybrid using CNN proposals and analytic matching must be named as such.

Reviewed implementation: a CNN proposal stage with a native-image detail path

The selected production design uses the existing synthetic-trained CNN only for object proposals. The new matching path is analytic; no external descriptors or newly trained fine-detail weights are introduced. This is a hybrid engineering change, not evidence that the CNN learned the new patch rule.

For each proposal, RGB contrast relative to a fitted perimeter-background plane estimates the foreground. Filling its internal holes gives broad geometry for alignment. A polar silhouette correlation proposes a rotation, followed by local refinement using overlap of canonical filled outlines. The same native alignment is reused by all fine-patch variants. These assumptions favor separated, high-contrast shapes and require new validation on textured or touching natural objects.

Only the reference selects patch centers: interior Sobel-gradient peaks, at most twelve, with a five-pixel suppression radius. Every selected neighborhood contains 7×7 samples. The query is sampled at the corresponding rotated/scaled location, with five fixed one-pixel translation choices. Per-patch mean subtraction and normalization reduce brightness and contrast dependence; a minimum RMS floor prevents artificial confidence from nearly constant vectors.

z(p) = (p − mean(p)) / ||p − mean(p)||₂, when RMS(p) ≥ 0.1 c_j = max over five local shifts ⟨z(reference_patch_j), z(query_patch_j)⟩ D = mean_j (1 − c_j) / 2 S = outline_overlap⁴ · exp(−8D)

This gives each selected local patch equal influence rather than weighting every pixel of the unchanged silhouette equally. The compressed control reduces and re-enlarges only fine RGB evidence with stride four; patch centers, coordinates, counts, weights and native outline alignment stay fixed. Native evidence still undergoes bilinear affine resampling, so it is not a claim of exact pixel preservation. The separately reported connected-feature moment control uses a more specific interior-structure prior. Both remain distinct from learned local descriptors in the cited papers.

Freeze and leakage boundaries

Use v11 TRAIN and old DEV for development only. Log every attempted configuration and the selection rule; do not choose a method using old TEST or fresh scene scores. Freeze the selected algorithm, all constants and ablation definitions before generating the new held-out compositions. Fresh DEV may calibrate each predeclared threshold; fresh TEST is evaluated once with those thresholds unchanged. No query annotation, grammar identity, renderer pose, mask or counterfactual label may enter scoring.

Compare the old CNN, the old fixed classical baseline, the selected full method and a detail-removed control on exactly the same new scenes. Keep the primary accepted-and-IoU≥0.5 recall at a DEV-calibrated false-positive limit, then report actual TEST false positives, pooled AUROC, proposal recall and within-pair ranking. Bootstrap whole families, keeping opposite enrollments and shared query pixels together. A higher recall with a materially worse false-positive rate requires explicit qualification.

Failure cases the implementation must handle

Blank or near-constant regions must not become strong matches after normalization. Crops must not use hidden target boxes. Near-symmetric outlines can admit several valid alignments, so a single canonical angle may be unstable. Small rasterized holes can merge, disappear or change moments under subpixel shifts. Multiple tiny features should be assigned consistently rather than each independently matching the easiest target. Any narrow synthetic success must later survive fresh natural-image evaluation before being called category learning.
