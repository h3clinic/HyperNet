# Third-party data and publication boundaries

This source package preserves the repository's existing licensing state. It does not add an MIT or other new copyright license grant, and it does not relicense external data.

| Original source | Attribution and source terms | Use in this experiment |
|---|---|---|
| [Gravity Spy Volunteer Classifications of LIGO Glitches](https://zenodo.org/records/13904422), version 1, 2024 | Kevin Crowston and the Gravity Spy project contributors; CC BY-NC-ND 4.0 as specified in the original record | Local-only human ballots used to derive consensus. No raw rows, volunteer identifiers, event-level derived ground truth, or label-linked score records are distributed here. |
| [Gravity Spy Machine Learning Classifications of LIGO Glitches from O1, O2, O3a and O3b](https://zenodo.org/records/5649212), version 1.0.0, 2021 | Jane Glanzer and collaborators; CC BY 4.0 as specified in the original record; the record asks users to cite Glanzer et al. (2023) | Event identity, detector, exact time and official two-second image URLs only. Machine-predicted classes/confidences are not the test labels. |
| [Gravity Spy labeled training data](https://zenodo.org/records/1486046) and the earlier project v15 artifacts | Preserve the original record's terms, attribution and version-specific file checksums | Supplies the existing reference/calibration roster and conservative prior-exposure exclusions. These historical inputs are required separately. |
| [Gravity Spy workflow 2360](https://www.zooniverse.org/api/workflows/2360) | Gravity Spy / Zooniverse; consult original service terms | A local snapshot of version 92.12 verifies the common 22-label task vocabulary. No workflow response is bundled. |

This table documents the records consulted; it does not assert that every remotely linked image or other asset inherits a metadata license. Acquire source materials directly under their applicable terms, preserve attribution, and assess any further redistribution separately. The package omits all real spectrogram pixels and derived real-image plots.

The independent human-consensus implementation and test code are included. They are not a redistribution of the resulting annotation table. Human votes are still influenced by workflow routing and task availability. The evaluation therefore describes a high-consensus selected sample rather than independent expert-certified physical truth.

The project may publish aggregate performance/count summaries and cryptographic commitments to locally retained evidence. A hash is an integrity commitment, not a substitute for access to the original evidence or a grant of rights to that evidence. Event-level reconstruction stays local and requires the official sources plus historical project inputs.
